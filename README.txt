PSU SALES & INVENTORY SYSTEM  (HTML + JavaScript + PHP + MySQL, XAMPP)

SETUP
1. Install XAMPP, start Apache and MySQL in the XAMPP Control Panel.
2. Copy the folder "psu_inventory" to C:\xampp\htdocs\
3. Open http://localhost/psu_inventory/install.php  (creates DB, tables, sample data)
4. Open http://localhost/psu_inventory/  and sign in.
5. Delete install.php afterwards.

LOGINS   admin/admin123   cashier/cashier123   clerk/clerk123
SETTINGS config.php (DB credentials, TAX_RATE e.g. 0.12)
NOTE     PDF/Excel export libraries (jsPDF, SheetJS) load from cdnjs, so the browser needs internet.
